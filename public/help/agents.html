AI agents

Ask an agent from the Mattermost Agents plugin to request a channel or Channel Admin for you.

When a System Admin turns on Offer tools to Agents, an agent can file requests for you. Ask it in plain words, for example "request a private channel called Marketing Team under team- and add @alice". The agent acts as you, so the request follows the same rules as the form: you must be a member of the team or channel, the prefix must be one your admin configured, and the request type must be turned on. As with the webapp form, the request goes to the approvers, even when you are a System Admin.

ToolWhat it does
list_prefixesLists the channel prefixes you can use, like /mattermost-request-hub prefixes.
request_channelRequests a new channel, like the form or /mattermost-request-hub channel <prefix> <Channel name> ....
request_channel_adminAsks for channel members to be made Channel Admins, like the form or /mattermost-request-hub channel-admin @user ....
list_my_requestsLists your pending channel and Channel Admin requests, like /mattermost-request-hub list.
get_request_statusLooks up one pending channel or Channel Admin request by ID. It finds your own requests, and requests you can approve; anything else reads as not found.

A request an agent filed for someone arrives in the approval channel like any other and names that person as the requester.

Agents can't approve

No agent can approve or deny a request. That stays with the approvers, on the approval card or with /mattermost-request-hub approve and deny.

For System Admins

Turn on Offer tools to Agents in System Console → Plugins → Mattermost Request Hub. It is off by default and takes effect on save. It needs the Mattermost Agents plugin and Mattermost 11.3 or later. Once it's on, the three tools above appear in the Agents plugin's own settings, where you choose which of them agents may use. The tools follow the Allow channel requests and Allow channel admin requests toggles. If an agent doesn't offer them, see Agents tools not showing.
