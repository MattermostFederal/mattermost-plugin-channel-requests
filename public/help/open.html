How to open a request

Same entry points cover most request types. Individual type pages list extras.

Right-side plug icon (Requests hub)

On the far right App Bar / plugin strip, click the plug icon. Choose Requests, then the tile you need (channel, team, bot, webhook, …).

Channel More actions

Click the channel name → More actions → the request item (for example Request a Channel, Request a Team, Request a Bot).

Native Mattermost spots

  • Channels: sidebar + → Request new channel
  • Channel Admin: Members panel → Request Admin
  • Teams: team sidebar menu → Request a Team / Request Team Admin
  • Bots & webhooks: Main Menu → Integrations → Bot Accounts / Incoming / Outgoing Webhooks (non–System Admins get the request form)
