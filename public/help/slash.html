Slash commands

One line per command — same forms as the hub and native menus.

  • /mattermost-request-hub docs — this documentation (overview)
  • /mattermost-request-hub channel — Request a Channel
  • /mattermost-request-hub channel-admin — Request Channel Admin
  • /mattermost-request-hub team — Request a Team
  • /mattermost-request-hub team-admin — Request Team Admin
  • /mattermost-request-hub team-member — Request Team Members
  • /mattermost-request-hub team-guest — Request Guest Invite
  • /mattermost-request-hub bot — Request a Bot
  • /mattermost-request-hub webhook-incoming — Incoming webhook
  • /mattermost-request-hub webhook-outgoing — Outgoing webhook

Markdown sources for contributors live in the plugin repo under docs/ (including admin-guide.md for System Console setup).
